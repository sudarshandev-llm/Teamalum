## 🛠️ Technical Architecture

Team Alum's web presence is built with a commitment to **performance, zero superfluous bloat, and rock-solid privacy**.

```
┌────────────────────────────────────────────────────────┐
│                      Client Layer                      │
│   • Semantic HTML5 & Modern Vanilla JS (ES6+ SPA)      │
│   • Custom Claymorphism UI & Hardware-Accelerated CSS  │
│   • Client-Side Analytics (Page Views & Content Views) │
└──────────────────────────┬─────────────────────────────┘
                           │
                 HTTPS / PostgREST APIs
                           │
┌──────────────────────────▼─────────────────────────────┐
│                    Data & Auth Layer                   │
│   • Supabase (PostgreSQL 15+)                          │
│   • Row Level Security (RLS) on all tables             │
│   • Google OAuth 2.0 with Dynamic RBAC Triggers        │
│   • Real-Time Question Triaging Pipeline               │
└────────────────────────────────────────────────────────┘
```

### Highlights:
- **Zero-Dependency Lightweight Client**: Handcrafted vanilla JavaScript with smooth single-page transition physics, instant responsiveness, and high accessibility (`a11y`).
- **Tactile Claymorphism Aesthetic**: Custom-engineered design system featuring soft layered shadows, dynamic floating gradient blobs, and responsive modal interactions.
- **Direct Engagement ("Ask Us")**: Integrated real-time Q&A pipeline where visitors can submit inquiries directly into the Supabase database. Every question is personally reviewed and answered by the team.

## 🛡️ Admin Dashboard v2

The repository includes a private, protected administrative portal (`admin.html`) equipped with granular role-based security:

- **Strict Access Control (RBAC)**: Managed via PostgreSQL Row Level Security (RLS):
  - `owner`: Full privileges, user role promotion, system settings.
  - `editor`: Inline answers to community questions, content updates.
  - `viewer`: Read-only access to operational logs and telemetry.
- **Real-Time Question Management**: Streamlined inbox allowing team members to triage incoming questions, craft inline answers, and record response timestamps.
- **Privacy-First Telemetry**: Lightweight visitor tracking (`page_views` and `content_views`) without intrusive third-party trackers or cookies.
- **Search Engine Isolation**: Explicitly excluded from search crawlers via `robots.txt` and excluded from `sitemap.xml`.

## 💻 Getting Started Locally

### Prerequisites
- Any modern web browser.
- A local HTTP server (Python, Node.js `serve`, or VS Code Live Server).

### 1. Clone the Repository
```bash
git clone https://github.com/sudarshandev-llm/team-alum.git
cd team-alum
```

### 2. Configure Environment
Create or edit `supabase-config.js` with your Supabase credentials:
```javascript
import { createClient } from 'https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2/+esm';

export const supabase = createClient(
  'https://YOUR_PROJECT_ID.supabase.co',
  'YOUR_SUPABASE_ANON_KEY'
);
```

### 3. Launch Development Server
```bash
# Using Python 3
python -m http.server 3000

# Or using npx
npx serve .
```

Open `http://localhost:3000` to view the public site or `http://localhost:3000/admin.html` for the administration portal.
